ChangedCambios

What 1.1 changed for youQué cambió para ti con la 1.1

  1. 01

    "Remember this" is saved right away"Recuerda esto" se guarda en el momento

    When you ask the agent to remember something, it writes a small file to ~/.aura-distill/inbox/ and shows you the path. The next /distill processes it and deletes it only after it is saved as knowledge. (INBOX, #47)

    Cuando le pides al agente que recuerde algo, escribe un archivo pequeño en ~/.aura-distill/inbox/ y te muestra la ruta. El siguiente /distill lo procesa y lo borra solo después de guardarlo como conocimiento. (INBOX, #47)

  2. 02

    Every distillation leaves a record, including its costCada destilación deja un registro, con su coste

    Each /distill adds one line to data/distill-ledger.jsonl (which conversation, when, how many signals) and one to data/economics.jsonl (tokens and file sizes). Both stay on your machine and are never synced or sent. (#46)

    Cada /distill añade una línea a data/distill-ledger.jsonl (qué conversación, cuándo, cuántas señales) y otra a data/economics.jsonl (tokens y tamaños de archivo). Los dos se quedan en tu equipo y nunca se sincronizan ni se envían. (#46)

  3. 03

    Two lighter helper agents (Token Saver)Dos agentes auxiliares más ligeros (Token Saver)

    scribe handles text-only jobs and starts about 14 times lighter than a default helper; scout reads code without being able to change it, about 3.5 times lighter. You can turn them on, off or remove them with installer flags, and the choice survives updates.

    scribe hace trabajos solo de texto y arranca unas 14 veces más ligero que un agente auxiliar normal; scout lee código sin poder cambiarlo, unas 3,5 veces más ligero. Puedes activarlos, desactivarlos o quitarlos con opciones del instalador, y la elección se mantiene al actualizar.

  4. 04

    Google Antigravity can use the same knowledgeGoogle Antigravity puede usar el mismo conocimiento

    A plugin lets Antigravity read and distill into the shared ~/.aura-distill/ store, with Time Index scripts for its transcripts. The installer does not set it up yet; that is a follow-up on #67.

    Un plugin permite que Antigravity lea y destile en el almacén compartido ~/.aura-distill/, con scripts de Time Index para sus transcripciones. El instalador todavía no lo configura; eso queda pendiente en #67.

  5. 05

    Updating no longer wipes your preferencesActualizar ya no borra tus preferencias

    An update used to overwrite rules/distill.md and reset your "Always-On User Preferences" to the empty template. Both installers now keep that section, and leave the file alone if the download fails.

    Antes, una actualización sobrescribía rules/distill.md y dejaba tus "Always-On User Preferences" como la plantilla vacía. Ahora los dos instaladores conservan esa sección y no tocan el archivo si la descarga falla.

PrivacyPrivacidad

  • Token Saver collects nothing; it only writes local files.
  • Standing policy: any future telemetry must be opt-in, aggregate-only, and have a published schema.
  • Token Saver no recoge nada; solo escribe archivos locales.
  • Política vigente: cualquier telemetría futura tendrá que ser opcional, solo con datos agregados y con un esquema publicado.
