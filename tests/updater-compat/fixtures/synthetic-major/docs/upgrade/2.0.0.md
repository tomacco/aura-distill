# aura-distill software edition 2.0.0: what changes before you adopt it (SYNTHETIC FIXTURE)

This guide is a synthetic test fixture for issue #79. It describes a hypothetical
software edition so the notice, the manifest and the release checks can be proven
before any real software edition exists. Nothing here is shipped.

## What changes

Version 2.0.0 replaces prompt-only reads and writes of the knowledge store with a
small local service. The files-only edition (1.x) stays supported; 2.0.0 is a
separate installation you choose.

## Runtime and dependencies

Adds one executable (the service binary, about 20 MB) and no language runtime. The
installer verifies its checksum before running it.

## Processes and startup

One background process, registered to start at login (launchd on macOS, a
scheduled task on Windows, a systemd user unit on Linux). It can be stopped and
removed with `aura-distill service remove`.

## Network and data destinations

Listens on 127.0.0.1 only. Makes no outbound connections. No account, no
telemetry. Knowledge never leaves the machine.

## Storage changes

Migrates `~/.aura-distill/` into a versioned layout after a dry run and a second
confirmation. The original files are kept as a read-only backup.

## Permissions

Runs as your user. Needs write access to `~/.aura-distill/` and to the client
configuration files the files-only edition already edits. No administrator rights.

## Resource use

About 30 MB of memory while idle and under 1% CPU; about twice the current store
size on disk during migration.

## Company approval

Installing a background service may need approval from your organisation. The
installer states what it will do and stops; it never assumes approval, never
installs silently and never retries on its own.

## Rollback

`aura-distill rollback` stops and removes the service, restores the backed-up
files-only store and reinstalls the 1.x adapters. Knowledge written after the
migration is exported to Markdown first.

## Staying on files-only

Do nothing. Auto-update never installs 2.0.0, and 1.x keeps receiving fixes.
