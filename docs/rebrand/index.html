How an aura grows

A tight loop, run at the end of real sessions. No background daemon, no magic.

01 · WORK

Sessions produce signals

A correction you made. A preference you stated once and expect to hold. A failure that surprised you both. These are worth keeping, and mid-session you can just say remember this.

02 · DISTILL

/distill

One command turns the session into durable knowledge. Each entry gets a confidence level and an origin, then lands in a markdown file a human can open and argue with.

03 · RECALL

The next session knows

Every session starts by reading a thin index. Knowledge relevant to the task loads before the first line of code. Everything else stays on disk, costing nothing.

It's just files

Your aura lives in ~/.aura-distill/ as plain markdown. Read it. Edit it. Version it. Grep it. Delete the parts you disagree with.

The agent treats it as authoritative memory. You treat it as text.

Knowledge that knows why it exists

Every entry carries an origin. A rule imposed by your tech lead is respected as a directive. A hunch from one session ships as provisional. When context changes, the agent knows which knowledge is ripe for revisiting, and which is untouchable.

origin: evidence

Earned through testing, data, or a failure you both remember. The default, and the strongest.

origin: directive

Imposed by authority. Fully respected in execution, and flagged for review when the authority or the context moves on.

origin: convention

Arbitrary but agreed. Naming schemes, style calls. Cheap to change, expensive to argue about twice.

origin: constraint

Forced from outside. Vendor lock-in, compliance, the API that only speaks XML. Not a preference.

experimental→ provisional→ validated→ hardened

Confidence rises with confirmation and falls with correction. The agent applies hardened knowledge without hesitation and treats experimental knowledge as a suggestion.

Real numbers or no numbers

Memory tools launch with big token headlines. We benchmark ourselves instead, A/B, with the methodology and raw data published next to every claim.

When a result comes back null, we publish that too. Our current measured verdict is deliberately modest: distilled memory reshapes where your tokens go before it provably shrinks the bill. That honesty is the product.
