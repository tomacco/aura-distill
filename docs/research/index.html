Research

Empirical findings on LLM knowledge systems. Each study uses A/B testing with identical prompts, models, and conditions. Raw outputs published alongside analysis.

4 studies · Core capability
Knowledge Retrieval
Does it USE knowledge correctly? A/B testing, memory degradation, confidence scaling, and operational tool reliability.
Headline: tool reliability test shows 0/5 vs 5/5 — strongest delta. Past failures become proactive prevention.
6/8 dimensions · Cognitive protection
Cognitive Bias Detection
Does it PROTECT the human? Anchoring, fatigue, loss aversion, authority, recency, and solution anchoring. Tested across engineer and PM personas.
Headline: distill poisoning discovered and solved. Specificity beats abstraction. Confidence gives permission to push back.
5/5 scenarios · Knowledge composition
Engineering vs Philosophical Frameworks
Can philosophical principles (Stoic/Pragmatist/Dialectical) complement engineering axioms? Tested on ambiguous decisions with no clear engineering answer.
Headline: conditions converge (68/67/68 of 75) — the interim “hybrid wins” signal did not survive the full run. Each scenario was won by a different condition.
7-system benchmark · User personalization
User Model: Always-On Preference Enforcement
Competitive analysis across 7 memory systems revealed user model as distill's weakest category. Root cause: preferences behind lazy-load gates. Fix: always-on inline preferences with enforcement hooks.
Headline: the winning system's advantage was placement, not architecture. Inlining 15 lines of preferences in the rules file eliminates retrieval failure.
656M tokens mined · Cost economics
The Token Economics of Remembering
Does memory pay for itself? 40 days of real transcripts priced distill's all-in overhead, measured what encoded knowledge actually prevents, and stress-tested a compressed index against held-out probes.
Headline: distill overhead is 5–6% of spend while ~85% of cost is context movement. Encoded environment gotchas stop recurring; behavioral rules don't (execution gap, quantified). Diet SPINE = trade-off knob, not free win.
6 archetypes × 3 tiers · Cost economics
Best Model for Everything? Model Routing
Which task shapes survive a downgrade to cheaper models? Blind-judged archetype battery, an adversarially-filtered routing landscape, and a test of whether a knowledge file changes delegation choices.
Headline: lookup/rule-shaped work survived Haiku untouched — the one wrong extraction answer came from the frontier arm. Stated routing judgment is near-perfect; revealed behavior is a 100% frontier monoculture. The gap is habit, not knowledge.
0 benchmark tokens · Cost economics
The Benchmark We Refused to Run: Pre-Distill Marks
Should every session write signal marks so distillation gets cheap? An adversarial review killed the benchmark design (every bias pointed toward a false APPROVE), then free arithmetic on 40 days of real usage killed the feature's token case.
Headline: the best-case saving is 0.3–2.2% of session cost — a cheap-tier batch cold read at distill time is already too cheap to beat. Discarded without spending a benchmark token. Run the arithmetic before designing the experiment.

Methodology

Every finding is reproducible. Same model, same prompts, same conditions. Raw outputs published.

Test subject

Claude Code (Opus 4.6) running non-interactively via a second instance ("sandbox") with separate config.

A/B framework

Same prompt runs twice: once without knowledge (control), once with distill rules + knowledge files (treatment).

Persona testing

Sofia Chen: fictional lead engineer with realistic cognitive biases, contradictions, and communication style.
